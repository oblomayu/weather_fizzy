#Лабораторная работа 3. Нечёткая экспертная система для анализа погоды
##Экспертная система на основе нечёткого вывода (алгоритм Мамдани), которая оценивает погодные условия в Казани, Москве и Санкт-Петербурге. Система сравнивает текущую погоду с климатическими нормами и выдаёт рекомендации.

##Что делает программа
1. Получает текущую погоду по трём городам из **OpenWeatherMap API**.
2. Загружает историю за последние 5 лет из **Open-Meteo Archive API** (среднесуточные температура, влажность, скорость ветра). Результат кэшируется в CSV.
3. Считает климатические нормы (среднее и стандартное отклонение) по сезонам: зима, весна, лето, осень.
4. Переводит числа в лингвистические значения с учётом города и сезона («холодно для лета», «оттепель» и т.д.).
5. Строит нечёткую систему Мамдани на **scikit-fuzzy**: на входе температура, влажность и ветер, на выходе уровень комфорта от 0 до 100.
6. Сравнивает текущие значения с нормами (z-оценка) и выявляет аномалии.
7. Формирует рекомендации и строит таблицу и графики.

## Как работает нечёткий вывод

| Этап Мамдани | Реализация |
| --- | --- |
| Фаззификация | `fuzz.interp_membership` по термам температуры, влажности и ветра |
| Агрегирование | операция И (`&`) в условиях правил |
| Активация | отсечение выходных термов по степени истинности правила |
| Аккумуляция | объединение результатов всех правил |
| Дефаззификация | центр тяжести (по умолчанию в `ControlSystemSimulation`) |

**Входные переменные**

| Переменная | Универсум | Термы |
| --- | --- | --- |
| Температура, °C | от -30 до 40 | очень холодно, холодно, прохладно, комфортно, тепло, жарко |
| Влажность, % | от 0 до 100 | сухо, нормально, влажно |
| Ветер, м/с | от 0 до 30 | штиль, умеренный, сильный |

**Выход:** комфорт (от 0 до 100), термы «плохо», «приемлемо», «хорошо».

**Учёт сезона и города**

- Границы термов температуры зависят от сезона.
- Для Казани зимой границы сдвинуты на 3°C вниз (жители привыкли к более суровой зиме), для Петербурга летом на 2°C вниз.
- У Петербурга ниже порог «сильного» ветра и «высокой» влажности (морской климат, прибрежный ветер).
- База правил: 54 базовых правила (6 × 3 × 3) плюс экспертные правила для каждого города, например «Петербург: высокая влажность и сильный ветер дают плохой комфорт».

## Установка
```bash
python -m venv .venv
source .venv/bin/activate        # macOS / Linux
# .venv\Scripts\activate         # Windows

pip install requests numpy pandas matplotlib scipy networkx scikit-fuzzy
```

## Запуск

```bash
python weather_fuzzy.py
```

Настройки в начале файла:

| Параметр | Назначение |
| --- | --- |
| `HISTORY_YEARS` | сколько лет истории загружать (по умолчанию 5) |
| `SHOW_PLOTS` | `False`, чтобы только сохранять картинки без открытия окон |
